# 책다락

평산책방과 진주문고의 추천책을 대화로 찾아보는 정적 웹앱입니다.

## 시작하기

Chrome 또는 Edge에서 `index.html`을 직접 여세요. 서버나 API 키는 필요하지 않습니다. 첫 대화에는 라이브러리와 모델 다운로드를 위한 인터넷 연결, WebGPU 지원 브라우저, 충분한 GPU 메모리가 필요합니다. 모델을 실행할 수 없어도 BM25 검색 결과와 도서 카드는 표시됩니다.

## 기술 스택

- 화면: HTML, CSS, 순수 JavaScript. 빌드 과정 없이 로컬 파일로 실행합니다.
- 대화: [WebLLM](https://github.com/mlc-ai/web-llm)과 `Qwen2.5-0.5B-Instruct`를 사용합니다. 추론은 브라우저의 WebGPU에서 실행하며, 웹 호스팅에서는 워커가 화면과 별도로 처리합니다.
- 의미 검색: [Transformers.js](https://huggingface.co/docs/transformers.js/index)와 `multilingual-e5-small`로 질의와 책 소개의 임베딩을 계산합니다. 웹 호스팅에서는 워커가 계산합니다.
- 데이터: `books-data.js`에 도서 정보와 출처별 추천사를 저장하고, 표지는 `covers/`에 보관합니다.

## 동작 원리

1. `search.js`가 제목, 추천사, 태그, 추천인의 단어와 한글 2글자 조각으로 BM25 점수를 계산합니다. 제목에는 더 높은 가중치를 줍니다.
2. 감정·분위기 등 의미 중심 질문에는 BM25 상위 후보 12권의 임베딩 유사도를 계산해 점수를 합칩니다. 임베딩 모델을 불러올 수 없거나 검색 시간이 초과되면 BM25만 사용합니다.
3. `app.js`가 검색 결과의 제목·원문 추천사·추천인 정보를 로컬 LLM에 전달해 추천 이유를 작성합니다. 도서 카드와 원문 링크는 검색 결과에서 직접 만듭니다.

책 추천 요청에는 상위 4권을 보여주고, 연도·월이나 평산책방 추천책·문재인의 추천책 전체 목록을 요청하면 해당 범위의 책을 모두 보여줍니다. 한 책에 추천 기록이 여러 개면 카드는 한 장으로 묶습니다. 인사나 일반 질문에는 도서 검색 없이 답하고, 일반 대화에는 같은 로컬 모델을 사용합니다. 대화 기록은 현재 탭의 메모리에만 유지합니다.

우측의 **오늘의 추천책**은 브라우저의 날짜를 기준으로 두 출처에서 번갈아 5권을 고릅니다. 같은 날에는 같은 목록을 보여주며 다음 날 바뀝니다.

왼쪽 **추천 목록**은 도서 데이터에서 출처별 건수를 계산해 만듭니다. 월별 기록은 연도 아래에, 그 밖의 기록은 목록별로 묶습니다. 목록을 누르면 해당 추천 기록의 책을 바로 보여줍니다. 출처나 월별 기록이 추가되면 탐색 항목과 건수도 함께 갱신됩니다.

## 도서 데이터

진주문고의 월별 추천 34개 글(2023년 12월~2026년 9월) 660건, 평산책방의 [평산책방 추천책](https://www.psbooks.kr/75) 171건과 문재인의 추천책 [재임 전](https://www.psbooks.kr/84) 36건·[재임 중](https://www.psbooks.kr/85) 17건·[퇴임 후](https://www.psbooks.kr/86) 123건을 담았습니다. 같은 책의 추천 기록을 합친 전체 목록은 977권, 추천 기록은 1,007건입니다. `recommendations` 배열에 출처, 추천 시기, 추천인, 원문 소개를 함께 저장합니다.

진주문고의 월별 게시물 링크는 `jinju-monthly-posts.json`에, 표지 이미지는 `covers/`에 모았습니다. 진주문고 표지는 `covers/jinju/YYYY-MM_NN` 형식으로 저장하며, 큰 원본 이미지는 화면 표시 크기에 맞게 줄였습니다. 평산책방 글은 게시판을 구분하고 `<추천글>`·`<출판사 서평>`·`작가의 말` 등 원문에 표시된 성격을 추천인 필드에 기록했습니다. 문재인의 추천책에서 추천일이 없는 5건, 평산책방 추천책에서 날짜가 없는 3건은 확인 가능한 시기만 저장했습니다. 진주문고 2026년 2월의 《오믈렛》은 게시물에 표지가 없어 도서 서지 정보의 표지를 사용했습니다.

원문에서 《파우사》와 《멘헤라를 위한 책》의 추천사 본문이 동일합니다. 두 원문을 그대로 보존하고, 《파우사》 쪽은 `attributionVerified: false`로 표시해 추천 근거에서 제외합니다.

평산책방의 《416 단원고 약전》 글에는 추천사 대신 `대통령추천글`이라는 자리표시자만 있어 이를 그대로 보존하고 추천 근거에서는 제외합니다.

책 목록은 `books-data.js`의 `window.BOOKS` 배열만 수정하면 됩니다. `index.html`이 이 파일을 직접 불러오므로 별도의 데이터 생성 단계가 없습니다.

새 책에는 `title`, `tags`, `cover`, `recommendations`를 넣습니다. 추천 기록에는 `source.name`, `source.url`, `period`, `recommender`, `text`를 넣습니다. `period`는 `2026년 9월`, `평산책방 추천 · 2026년 9월 19일`, `퇴임 후 · 2026년 9월 18일`처럼 게시판과 시기를 나타내며, 도서 자체에는 별도의 연도·월 필드를 두지 않습니다.
